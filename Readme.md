# BLE library 
library ini diguankan untuk kepentingan kecepatan dan penggunaan daya yang sedikit
respon esp32 dengan menggunakan library ini sanagt cepat karena mekanisme yang digunakan adalah funciton callback
serta library ini memilik efisiensi penggunaan memory yang sangat baik karena menggunakan pointer dan static method.
